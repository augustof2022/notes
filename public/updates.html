Version updates

What's new in your workspace, from small improvements to new ways to build your ideas.

The latest version is 0.10.1. Check the version shown in your app to see which build you're using. If an update is ready, choose Save and update to load it.

Version 0.10.1

Latest

October 30, 2026

Edit text directly on the board

  • Write in place. Text and diagram labels edit at their board position. The separate text editor window has been removed. Click elsewhere, Escape, or Ctrl+Enter to finish; edits autosave as you type.
  • Type / for commands. Choose headings, bullets, numbered lists, checklists, bold, underline, quotes, code, and more from a small menu at the caret. Search by name or use arrow keys and Enter.
  • Use Markdown while typing. ## plus Space creates Heading 2. * or - plus Space starts bullets. Select words or all text to apply bold, italic, and underline with the selection bar or keyboard shortcuts.
  • Paste with your preferred formatting. Ctrl+V retains formatted web text or interprets Markdown. Ctrl+Shift+V keeps literal text. Existing formatting, diagram branch shortcuts, search, and PNG export remain supported.

Version 0.10.0

Previous

October 30, 2026

Visual text formatting and Markdown

  • Format every text object. Edit standalone text and diagram labels with a visual toolbar for headings, bold, italic, underline, colors, fonts, lists, checklists, quotes, code, links, and tables.
  • Choose how Markdown pastes. Ctrl+V formats Markdown on the board or inside a text object. Ctrl+Shift+V preserves the literal source. Use Cmd on Mac. Switch between Visual and Markdown tabs or copy the Markdown for another app.
  • Keep diagram creation flowing. Tab saves the label and adds a child. Shift+Tab adds a sibling under the same parent. Touch buttons provide the same commands. New labels inherit a visible text color from formatted parents.
  • Keep formatting with your board. Text stays searchable and attached when moved, resized, or rotated. Formatting survives sync, reload, backups, and PNG export. Generated text previews need no image uploads or database migration.

Version 0.9.0

Previous

October 25, 2026

Partial ink erasing and draw-and-hold shapes

  • Partial or object erasing. Use a circular partial eraser to remove only the handwriting under its adjustable tip. Choose object erasing for whole strokes, shapes, or images. Press E to reuse your chosen mode; Undo restores erased ink.
  • Draw and hold to shape. Pause briefly with the pen still touching the board, then lift to clean up a recognizable line, circle, ellipse, square, rectangle, or triangle. Lift immediately to preserve freehand ink. Disable correction in Writing tools or Undo to restore the original ink.
  • Editable vector stamps. An expanded palette includes 48 markers for clarification, research, reminders, tasks, risks, and more. New stamps resize and recolor as native vector groups without image uploads. Existing image stamps and saved choices remain supported, including Keep stamping.
  • Keep your current setup. Google sign-in, Drive renewal, sync safeguards, Trash, and movable customizable toolbars remain in place. Writing tools appear in Board actions and its More menu. No new database migration is required.

Version 0.8.0

Previous

October 25, 2026

Sign in once and return to your workspace

  • Start with Google. Continue with Google signs you in or creates your Note account. The workspace opens after a valid Google-linked Note login is ready.
  • Remember your login. Note restores its saved session and refreshes it in the background. A still-valid login can reopen cached boards offline; a new sign-in or an expired session needs internet.
  • Keep Drive separate. Note login and saved Drive access renew separately. Temporary connection problems do not ask you to grant Google permission again. Revoked access or a genuine security sign-out can still require signing in or reconnecting.
  • Preserve earlier device boards. Existing device-only notes stay on this browser. After signing in, use Settings & storage → Cloud sync → Copy this device’s boards into my account when you want to import them. Nothing is copied automatically.
  • Sign out safely. Signing out hides the workspace and clears the browser’s Drive access cache. It keeps existing local board data. About, updates, privacy, and terms remain public.
  • Use the existing cloud setup. This release needs no new Supabase SQL migration. Saved Drive access continues to use the existing private renewal function.

Earlier releases

v0.7.0Keep Drive connected for uploading and viewing images

October 23, 2026

Keep Drive connected for uploading and viewing images

  • Remember valid access. Reopening Note reuses a short-lived, account-verified Drive connection with its original expiry. Refreshing your Note login does not disconnect Google.
  • Renew in the background. With the one-time private Drive renewal setup complete, Note renews Google access for both uploads and image loading. Concurrent requests share one renewal and retry once if Google rejects an expired token.
  • Reconnect only when needed. Temporary network errors, request limits, and full Drive storage have their own explanations. Revoked or expired Google consent still requires reconnecting. Missing renewal setup is shown separately.
  • Publish ready boards sooner. Upload two images at a time and publish each board as soon as its own image files and cloud locations are ready, while unrelated images continue uploading.
  • One-time owner setup. Deploy the private Supabase function and credential-table migration, then enable saved Drive access once in Images & search. Google secrets and refresh credentials stay out of the frontend and GitHub. See the setup guide.
v0.6.0One board across devices, with a complete Trash

October 18, 2026

One board across devices, with a complete Trash

  • Viewing stays local. Panning, zooming, brush preferences, and image-loading details no longer count as competing board edits. Opening a folder or board on another device does not create a copy.
  • Keep one board. Sync reconciles independent edits on the original board. If both devices changed the same content, Sync details lets you compare versions and choose which to keep. Extra boards are created only by your explicit Duplicate or import actions.
  • Delete permanently or empty Trash. Review and confirm the items to remove. Synced deletion erases their saved content and retains an inert marker so an older offline device cannot restore the same ID. Shared image files stay in storage.
  • Update every device. Load this version on both devices to stop older builds from creating conflict copies. The copy fix works with the existing cloud schema. Permanent Trash deletion needs the one-time permanent-trash SQL update in Supabase.
v0.5.3See images load across devices

October 18, 2026

See images load across devices

  • Open the board right away. Show notes and cached images first. Retrieve missing images three at a time and display each as it arrives.
  • Know what is happening. A loading count and persistent image errors show above the canvas and in Sync details. The header shows when images are loading or need attention, separately from board uploads.
  • Recover without reopening. Retry images directly, or let Drive reconnect, Sync now, returning online, and newly received image details retry them. A board revision does not need to change. PNG export waits for missing files or explains a download failure.
  • Keep downloads on this device. Cache retrieved images, share duplicate requests, and use cached files when reopening or offline. Stop stalled downloads with a retryable timeout, and explain Drive access or missing-file errors.
v0.5.2Unblock boards on older cloud databases

October 17, 2026

Unblock boards on older cloud databases

  • Compatible saves. When an older database is missing creation-date columns, save boards and folders with the same account access policies and revision checks. A missing date field no longer has to block an upload.
  • Repair partial upgrades. Sync details links to a small SQL repair for missing date columns or broken creation-date triggers. Run it in your project’s Supabase SQL Editor, then sync again. Existing boards, files, revisions, and edit times are preserved.
  • Safe reruns. The full setup script and focused repair now handle partially installed date fields and existing triggers. Unknown original dates stay labeled as estimates.
v0.5.1Faster sync with clear pending details

October 17, 2026

Faster sync with clear pending details

  • Know what is waiting. Use the question mark beside sync to see pending boards, folders, and images, their names, specific errors, and the last cloud check and completed sync. Failed saves show “Sync needs attention.”
  • Faster across devices. Changes upload after a short pause in editing. Open devices check every 15 seconds and refresh when you return to the app or reconnect. Revision checks avoid downloading unchanged boards on every poll.
  • Reliable manual sync. Flush the open board before uploading. A second request during an upload queues a fresh pass that includes newer edits.
  • One blocked item does not stop the rest. Continue uploading unrelated boards and receiving cloud changes when a board, folder, or image fails. Each blocked item keeps its error for retry.
  • Uploaded images can publish sooner. Searchable-text updates no longer block a board whose image file and cloud location are already saved. Recover an existing cloud image location instead of uploading it twice.
  • Avoid false pending changes. Reordered cloud settings no longer count as new edits, and independent element edits with the same version number are recognized.
  • Keep edits safe. Keep the editor covered until its board loads and defer cloud refreshes while local edits are being saved. Preserve edits made during a request, recognize an already completed retry, keep genuine conflict copies, count pending Trash changes, and time out stalled cloud requests.

Arrange your board toolbars

  • Move and resize. Drag the grip to position Board actions or Drawing tools. Drag the right edge to change its width, or use the width slider in ⋮ More. Keyboard arrow keys work on the grip and resize handle too.
  • A single row. Each bar keeps its controls and minimize button on one row. Extra controls are available in ⋮ More, including on smaller screens.
